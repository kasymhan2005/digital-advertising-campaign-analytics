# Dataset

`data/raw/conversion.csv` is included in the downloadable ZIP for local use and is deliberately ignored by Git. The dataset was provided by the user for an educational assignment; redistribution rights have not been independently confirmed.

For a public GitHub repository, upload the project files but exclude `data/raw/conversion.csv` unless you have the right to publish it. Streamlit shows a clearly labelled **synthetic demo** when this file is not available, and allows users to upload a compatible CSV in the sidebar. This is not the real dataset.

Expected columns:
`ad_id, xyz_campaign_id, fb_campaign_id, age, gender, interest, Impressions, Clicks, Spent, Total_Conversion, Approved_Conversion`

No currency was specified in the data description. All spending is reported in **dataset currency units**, not USD. There is no timestamp, revenue, attribution window, or experiment assignment in the dataset.
